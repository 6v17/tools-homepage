v1.0.83 更新说明

核心优化

  • 搜索逻辑优化，部分模型抽帧与语义化链路改进
  • 新增搜索范围选择、图文混合搜索与搜索预设
  • 适配 Chinese-CLIP，中文文本搜索更精准
  • GitHub 增加全链路 GPU 抽帧推理流分支
  • 新增本机搜索接口：在「设置 → 本机搜索接口」复制接入说明，发给 Cursor 等 Agent（建议附带安装目录），即可协助检索素材

问题修复

  • 修复部分已知问题，提升整体稳定性

其他说明

  • 混剪溯源功能不符合软件定位，v1.0.83 起已移除
  • 因 OSS 托管成本较高，后续模型将统一上传至 123 云盘；注册登录后仍可免费、不限速下载
