VideoSeek

v1.0.85 更新说明

新功能

  • 新增「视频笔录」：按单视频 chunk 自动分镜，抽帧送入理解模型生成每段描述，并汇总为完整笔录
  • 支持导出笔录，便于归档与二次编辑

接口与搜索

  • Agent API 新增视频笔录能力，可与 Cursor 等 Agent 联动调用
  • 理解模型支持本机 LM Studio、Ollama，以及云端 API Key 等多种接入方式

问题修复

  • 修复新下载导入后显示异常的问题
