VideoSeek

本地视频检索工具，支持以图搜视频与文本搜索，帮你整理素材库、快速定位目标片段。

v1.0.84 下载
v1.0.84 更新说明

新功能

  • 新增「素材篮」：单次检索会话中可暂存多个视频片段，像购物车一样勾选管理，支持一键导出片段或片段清单 JSON

接口与搜索

  • 本机搜索接口重构：规范更严格、格式更统一，便于 Cursor 等 Agent 接入调用
  • 局域网搜索与 PC 端对齐，统一支持三种搜索策略

体验优化

  • 精简设置项，移除已废弃或无用的参数

问题修复

  • 修复若干已知问题，整体运行更稳定
