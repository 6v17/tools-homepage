用文字或截图，在本地素材库里找片段

索引、检索都在本机完成，不上传你的视频。预览命中后直接导出 MP4。

下载 v1.0.87 教程 GitHub

功能

本地视频库

添加文件夹，同步后自动抽帧建索引，支持多库。

文字 / 图片搜索

描述场景或上传参考图，返回相似画面的时间段。

预览与导出

时间轴预览命中片段，确认后导出 MP4。

理解笔录 · Agent API

可选生成 chunk 描述与整片总结；本机 HTTP 接口供 Agent 调用。

v1.0.87 更新说明

硬字幕检索

  • 新增字幕库：对片中硬字幕做 OCR，按台词关键词搜时间点（不再依赖旧版语音 ASR 主路径）
  • 字幕库与画面库拆分：OCR 与 CLIP 画面索引互不绑架，可单独加库、提取、维护
  • 支持精确 / 模糊匹配；结果带命中高亮，方便对照原文
  • 提取流程：有声段 VAD → 抽帧 → RapidOCR，进度与阶段提示更清楚

手机端 & Agent

  • 手机局域网搜索对齐桌面：图搜模式 + 字幕检索
  • Agent 本机接口：命中结果自动回填视频绝对路径，一键「搜完导出」可用
  • 导出更灵活（支持输出目录自动命名）；字幕库就绪状态语义更清晰

稳定与体验

  • 修复部分安装包「提取字幕无反应 / 失败」（RapidOCR 配置缺失）
  • 差电脑 / 核显 OCR 中途崩溃时自动切 CPU 继续（可能更慢，但不易半路挂掉）
  • 理解页首进卡顿优化；搜索页播放器区域滚轮等交互修复
  • 搜索结果状态条更干净；导出状态提示更短更清晰
  • 清库 / 卸模型后的崩溃与状态错乱若干修复；日志自动轮转与清理
  • 移除鸡肋的视频理解 YOLO 依赖；合成搜等模式更聚焦

升级提示

  • 请从官网下载最新安装包覆盖安装
  • 使用字幕检索前请先导入 RapidOCR 模型，并在「字幕库」中提取字幕
  • 差电脑提字幕变慢属正常；问题反馈 QQ 群 1033551438

系统要求

  • Windows 10 / 11（64 位）
  • 首次使用需导入运行资源（模型、FFmpeg，约数 GB 磁盘空间）
  • 推荐 16 GB 内存；有独显时可走 DirectML 加速
  • 素材库路径需本机可读写（支持 NAS 映射目录）
